# Architecture

## Project Overview
This project is a frontend form for initiating calls, integrated with MindFlow's Event-Driven Workflows (EDW).

## Repository Information
- **URL:** https://github.com/Sparkozzy/call_form_front.git
- **Main Branch:** `main`

## Directory Structure
- `.agents/`: AI Agent configurations and skills.
- `docs/`: Technical documentation.
- `paginadedisparomindflow/`: Subdirectory containing the core application logic.
    - `pagina-de-disparo/`: The main frontend application.
        - `index.html`: Main UI.
        - `server.js`: Node.js backend for handling requests.
- `.env`: Environment variables (ignored by git).
- `.gitignore`: Git exclusion rules.
